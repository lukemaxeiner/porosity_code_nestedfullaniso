# Porosity Histogram Visualization

This folder contains a plug-and-play Python script for plotting histograms from generated porosity VTK files.

## Setup

Open a terminal in this folder and install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run

Use the default generated realization:

```bash
python porosity_histogram.py
```

By default, the script:

- reads `S4_1.0487_2201_NI8crop_gaussian_realization_001.vtk`
- uses 50 histogram bins
- displays an interactive plot
- saves `porosity_histogram.png` in this folder
- prints summary statistics to the terminal

## Options

Plot another VTK file:

```bash
python porosity_histogram.py --vtk "../GENERATED_POROSITY_FIELDS/another_realization.vtk"
```

Change the bin count:

```bash
python porosity_histogram.py --bins 100
```

Limit the displayed range to physical porosity values from 0 to 1:

```bash
python porosity_histogram.py --physical-range
```

This option hides out-of-range values from the plot only; it does not modify or rewrite the VTK file.

Save without opening an interactive window:

```bash
python porosity_histogram.py --no-show
```

Choose another output image location:

```bash
python porosity_histogram.py --output my_porosity_histogram.png
```

Overlay the measured blockwise porosity field:

```bash
python porosity_histogram.py --measured "../S4_1.0487_2201_NI8crop_porosity_field.tif"
```

The measured field is a TIFF produced by `POROSITY_FIELD = YES`. Replace the example filename with the `_porosity_field.tif` file generated by the C project.

When `--measured` is used, both distributions are plotted with probability-density normalization so datasets with different numbers of samples can be compared. The measured values are shown as a filled histogram and the reconstructed values as an outline.

Limit both distributions to the physical range:

```bash
python porosity_histogram.py --measured "../S4_1.0487_2201_NI8crop_porosity_field.tif" --physical-range
```

Choose another output image location:

```bash
python porosity_histogram.py --output my_porosity_histogram.png
```

## About the data

The script reads values from a legacy ASCII VTK `SCALARS porosity` point-data array. Gaussian realizations can contain values outside the physical porosity range $[0,1]$, so the script reports values below zero and above one separately.
